# Güvenlik Politikası / Security Policy

**Türkçe** · [English](#english)

## Desteklenen sürümler

| Sürüm | Güvenlik güncellemesi |
|---|---|
| 1.0.x | ✅ |

## Açık bildirme

Güvenlik açıklarını **herkese açık issue olarak bildirmeyin.**

- GitHub'da depo sayfasındaki **Security › Report a vulnerability** (özel bildirim) bağlantısını kullanın: https://github.com/cumabozkurt/bozkurt-cms/security/advisories/new
- veya e-posta: **info@cumabozkurt.tr** (konu: `[GÜVENLİK] BOZKURT CMS`)

Lütfen etkilenen sürümü, adımları ve mümkünse bir kavram kanıtını ekleyin. 72 saat içinde dönüş yapılır; düzeltme yayınlanana kadar ayrıntıları paylaşmamanızı rica ederiz. Sorumlu bildirimde bulunanlar sürüm notlarında teşekkürle anılır.

Mimari ve alınan önlemler: [docs/GUVENLIK.md](docs/GUVENLIK.md) · Denetim raporu: [docs/GUVENLIK-DENETIMI.md](docs/GUVENLIK-DENETIMI.md)

## English

### Supported versions

| Version | Security updates |
|---|---|
| 1.0.x | ✅ |

### Reporting a vulnerability

Please **do not report security issues in public GitHub issues.**

- Use GitHub's private reporting: **Security › Report a vulnerability** — https://github.com/cumabozkurt/bozkurt-cms/security/advisories/new
- or e-mail **info@cumabozkurt.tr** with the subject `[SECURITY] BOZKURT CMS`.

Include the affected version, steps to reproduce and, if possible, a proof of concept. You will get a
response within 72 hours. Please keep details private until a fix is released. Reporters are credited in
the release notes unless they prefer otherwise.

Security model: [docs/en/security.md](docs/en/security.md)
